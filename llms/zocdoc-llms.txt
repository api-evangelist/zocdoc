# Zocdoc API

> The Zocdoc API enables seamless integration with Zocdoc's healthcare appointment booking platform, allowing developers to access real-time provider availability, patient scheduling, and healthcare directory data. Developers can build applications that use Zocdoc's authoritative understanding of practice and provider availability to build applications that help patients find the right doctor, book appointments, and manage their healthcare.
